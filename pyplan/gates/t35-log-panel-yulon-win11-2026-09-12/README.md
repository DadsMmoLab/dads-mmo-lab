# T35 — the stage strip and the tones, on a real install on `yulon-win11`

The box: `yulon-win11` (Hyper-V, Windows 11, 1920×1080, Docker Desktop), the fork's Actions build of `yulon-phase8b` at `e71a74a4` (run 34663064692, T35 + T36) launched into the desktop session. Presses are UI Automation `InvokePattern` on the app's own widgets; the native folder pickers were driven by typing into their address bar and clicking Select Folder (`dialogkeys.ps1`, `dlgclick.ps1`, in the sibling T36 folder). Frames are Hyper-V thumbnails from the host (`vmshot.ps1`, 1024×768, the 16:9 screen letterboxed); every text capture carries the VM's `Get-Date -Format o`.

| stopped before the build | `03-stop.txt`, `frame-13-stopped.png` | Stop pressed 03:48:56; `install of wow-tortoise was cancelled; nothing remembered`; `D:\tortoise-test` (0.46 GB of clone) removed afterwards |

Two findings for a follow-up, neither a T35 regression: (1) git's `remote: Counting objects: N%` fragments are appended as one dimmed line each rather than rewritten in place — the parser knows `Receiving objects`, `Resolving deltas`, `Compressing objects` and `Updating files`, and the `remote: ` prefix hides the third from it (frame 03, the 58%…100% run); (2) a Stop during the containerized clone reads the killed `docker run` as a failure and tries the host-git fallback before the cancel is honoured (`03-stop.txt`: `exited 1: Updating files: 66% … falling back to host git`).

Not pressed here: the build's stage count and the map generator's per-map tiles (the install was stopped before its build to keep the owner's box; the unit tests carry both parsers), and a warning line in amber (none occurred in this run; the preflight's `[warn]` shape is the same classifier the unit tests cover).
