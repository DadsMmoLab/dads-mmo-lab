## The one thing that needs the owner

**`Restore-VMSnapshot` is refused by this harness.** 7.1's Ubuntu gate and 7.2's gate both begin
"restore `yulon-ubuntu` to `clean-ssh`", and that command cannot be issued from a Claude session
here — it is blocked as a destructive action, and working around a block like that is not something
to do quietly. `Start-VM` and a graceful `Stop-VM` both work; only the restore is closed.

So 7.1 and 7.2 are **not** blocked on knowledge or on machines. They are blocked on one command.
Either run it by hand:

```
ssh vmhost "Restore-VMSnapshot -VMName yulon-ubuntu -Name pre-7.2-gate-2026-09-02 -Confirm:$false; Start-VM yulon-ubuntu"
```

or add a permission rule so a session can. `pre-7.2-gate-2026-09-02` is a child of `clean-ssh` and
was made for exactly this gate; `clean-ssh` itself is the stricter starting point.

**Everything else that gate needs is ready and committed**: `pyplan/gates/press-driver.py` holds
the pty open for the whole run and answers the consent and sudo questions on their last lines,
which is the part that defeated the obvious approaches (`_terminal_prompter` declines everything
off a tty; a pty fed by a heredoc parks forever).
